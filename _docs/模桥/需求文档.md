# 模桥 ModelBridge 需求文档

版本：v0.1.5；日期：2026/10/21；状态：支持粘贴站点页面地址。

## 1. 背景与目标

用户经常需要使用新发布的模型。目前要手工查询模型名称、登录 Sub2API 查找 Key，并修改 Codex 配置。目标是在本机完成这一整条流程，降低重复操作和配置错误。

## 2. 适用范围

第一版用于 Windows 本地 Codex，联网发现范围为 OpenAI、Anthropic、Google、DeepSeek。用户已确认先支持这四家。站点为用户自行填写的 Sub2API 部署，访问权限由该站点决定。工具不购买订阅、不调整上游账号、不创建密钥或分组。

## 3. 角色与入口

唯一角色为本机使用者。双击应用进入本地窗口；连接站点、选择密钥、刷新模型、预览和应用均在窗口内完成。登录在站点自身页面完成，支持该站点页面提供的认证方式；工具不收集用户密码。

交付文件夹外层只保留一个主程序启动入口。内部辅助组件由工具自动使用，放入专用内部文件夹，用户不需要辨认或单独运行。

## 4. 主业务流程

填写站点地址并打开站点登录窗口；登录成功后读取当前账号的全部密钥；用户选择密钥后自动读取其模型参数；刷新官方资料查看本次新发现的模型；勾选模型；选择仅添加或同时切换连接；预览并确认应用；按提示重启 Codex；如需撤回，可手动恢复备份。

## 5. 关键业务场景

- 使用同一混合分组密钥访问多个厂商模型。
- 新模型未出现在站点列表，但用户持有准确模型名称：允许手动输入名称，不以站点列表缺失阻止发现或配置准备。
- 官方已发布、参数尚未适配：模型行提供处理入口，说明当前应登录、选择密钥、重试读取，还是索取并导入该模型的完整参数文件。能够从所选站点读取的参数自动处理，缺失的参数不凭空生成。
- 重复添加：已有模型保留，不重复追加。
- 需要换站点或密钥：预览清楚显示连接将改变；用户确认后才生效。
- 官方刷新部分失败：分别显示各来源本次结果，失败来源明确显示原因；不将旧数据代替本次刷新结果。
- 按厂商找模型：顶部卡片是唯一的厂商切换入口；列表保留“全部模型”用于取消厂商筛选，不再重复展示四家标签。切换时保留搜索词和已勾选的模型，官方资料入口独立使用。
- 查看新模型：刷新成功后，与同一来源上次成功读取的结果比较，新出现的名称标记为“本次新发现”并排在前面。首次成功读取只建立比较记录，不将全部模型标成新品；刷新失败不展示旧数据冒充成功，也不清除用于下次比较的成功记录。
- 输入模型名称或 ID：搜索框应有足够的输入空间，搜索图标居中；窗口缩小时搜索框独占一行，避免挤压筛选说明。

## 6. 核心规则

厂商发布信息、站点列出的模型、Codex 已配置模型分别具有独立来源。列表存在不表示真实调用已验证。模型参数由工具依据准确目录处理，不要求用户猜测，不从无关模型复制能力。

追加保留原模型及其他配置，第一版保持默认模型不变。明确新增的模型应显示在 Codex 模型列表中。默认选择“只添加模型”，保留当前连接；选择密钥、重新选择密钥均不会自动启用连接切换。“添加并切换站点 / Key”须由用户明确选择，主页面和预览均显示目标站点、密钥名称及掩码，并说明影响后续请求。模型配置写入成功与上游推理成功分别陈述。

密钥选择成功但目录读取失败时，仍显示当前选择及失败原因，允许手动重试；旧密钥的参数立即清除，不用于新密钥。自动读取不包含推理请求，不消耗模型调用额度。“本次新发现”表示工具比较结果，不代表厂商正式发布日期；修改来源配置后重新建立比较记录。

只读取当前登录账号有权限访问的全部 Key。密钥在界面仅显示掩码，不写普通日志，不传给厂商文档站点。

用户可以粘贴站点任意页面地址，包括首页、多层页面、查询参数和锚点。登录前由工具在同一站点内验证真实入口，不依赖固定页面名称；保留实际部署子目录，识别成功后在输入框显示实际地址，登录和后续读取复用该入口。识别过程只读取公开信息，不携带账号凭据或 Key。无法验证时说明原因，不打开错误登录地址、不替换已有账号和设置。按用户填写的 HTTP 或 HTTPS 协议连接，保留端口；识别不跟随跳转或更换站点。HTTP 站点显示连接未加密提示，不额外阻止登录；HTTPS 正常验证证书。

## 7. 异常与边界

登录失效要求重新登录；分页失败时不以部分密钥集冒充全部。参数不完整时不能生成凭空补齐的目录。配置在预览后被外部修改时停止应用，要求重新预览。校验失败时原配置保持完整。应用目录或 Codex 目录不可写时显示具体错误。

工具不保证所有新模型发布当天完成适配；站点的版本、权限、模型路由和上游额度仍决定实际服务能力。第一版管理用户级配置，若当前启用的配置档案覆盖了待修改的目录或连接，则停止应用并说明原因。手动恢复只恢复本工具保留的配置状态，不调整远端账号。

## 8. 上下游职责

厂商负责模型正式资料；Sub2API 负责认证、密钥、路由、协议转换和计费；Codex 负责加载模型目录并执行任务；本工具负责连接选择、模型发现、本地配置校验、追加和手动恢复。

## 9. 验收关注点

四家官方目录可分别刷新并展示来源时间；站点登录成功后读全分页密钥并供选择；选择项不会因为旧请求迟到而串号；大数字 ID 全程使用字符串；预览不泄漏密钥；应用前真实 Codex 解析器验证；原配置、模型和注释得到保留；多次点击不会重复提交；备份可以手动恢复；测试不得修改真实 Codex 配置或消耗用户上游额度。

## 10. 版本记录

v0.1.0（2026/10/21）：依据本会话建立第一版完整需求。用户已授权在指定目录开发和生成 Windows 可执行程序。

v0.1.1（2026/10/21）：用户反馈 HTTP 站点被拦截、两个程序入口难以理解；确认支持原 HTTP 地址，并将辅助组件归入内部文件夹。

v0.1.2（2026/10/21）：厂商卡片支持直接筛选并与标签联动；加宽搜索框并修正图标对齐。

v0.1.3（2026/10/21）：选 Key 自动读取、缺参数处理入口、新发现标记、明确添加与连接切换、去除重复厂商标签；以上五项由用户一并授权。

v0.1.4（2026/10/21）：修复粘贴登录页或密钥页地址导致接口请求错误；支持识别已知页面后缀、保留部署子路径并显示实际站点入口。

v0.1.5（2026/10/21）：改为登录前验证真实站点入口，支持任意页面路径，保留部署子目录，识别失败保留已有状态。
