# 模桥 ModelBridge 设计文档

版本：v0.1.6；日期：2026/10/21；状态：支持账户刷新、连接检查及独立 API 地址。

## 1. 设计目标与对象

设计对象包括本地桌面窗口、站点登录会话、密钥选择、模型来源、Codex 配置方案、配置备份。目标是在一条清楚的操作链中完成模型追加，并保留可审查、可恢复的配置变化。

## 2. 分层职责

页面负责输入、筛选、选择和预览；本地应用负责状态和操作互斥；站点连接负责当前用户数据；模型发现负责资料来源及时间；配置组件负责读取、合并、解析校验、备份和原子替换；凭据组件负责 Windows 当前用户加密存储。

## 3. 状态设计

登录会话独立于 Codex 当前配置；网页登录完成后先保留本轮凭据，再读取账户和密钥。读取期间禁止选择；网络或分页失败保留凭据及上次完整资料并标为未更新，成功后整体替换。只有账户资料就绪且登录有效时才可选择或切换连接。模型目录保存来源、获取时间、完整元数据是否可用及是否已配置；这些维度不合并为单一“可用”结论。

准备方案绑定站点、选中的密钥、模型条目、配置快照和目录快照。改变选择或读取到新的配置后，旧方案不能直接应用。

## 4. 处理流程与页面结构

页面上方显示产品名及设置入口。左侧连接卡片提供网站登录、刷新账户、连接检查、密钥选择、可修改的 API 地址及 Codex 状态；右侧主区提供厂商筛选、搜索、联网刷新和模型列表；底部操作区显示选择数量与预览按钮。配置和备份位于独立设置弹窗，避免主流程出现实现细节。

顶部厂商卡片负责选择厂商，列表工具栏只保留“全部模型”、当前筛选说明和搜索框。点击卡片只更新筛选控件和列表，保持搜索输入、已勾选模型及键盘焦点；官方资料按钮独立操作。搜索框在宽窗口保持足够宽度，空间不足时换行，图标居中且不拦截输入。

选择密钥后，在同一次串行操作中清除旧站点参数并读取、校验新目录；页面展示读取进度及结果。失败保留密钥选择，展示原因及重试入口，成功与空目录分别给出数量。缺参数行可打开处理说明：未登录或未选密钥时定位相应入口，读取失败时可重试，读取成功仍缺失时说明站点暂未提供并支持导入。导入沿用现有校验，不生成猜测参数；完成后可直接勾选该模型。

底部显式展示“只添加模型”和“添加并切换站点 / Key”。初始、换密钥或退出账号时选择仅添加；只有用户自行选择第二项才提交连接变更。操作说明与预览同时展示连接保留或目标站点、密钥，提交中禁止改动选择。

登录打开独立站点窗口，该窗口不暴露本地应用操作能力。只在确认站点来源一致后读取登录凭据，清除窗口内的本轮认证存储并关闭页面，再验证当前用户和全部密钥。下次更换账号重新登录，不直接复用上一账号的页面认证。用户密码由站点页面处理。取消登录或退出登录结束相应会话。

站点输入支持 HTTP 和 HTTPS。粘贴页面地址后，先去掉页面参数和锚点，从当前路径向上验证公开站点信息；最先通过验证的路径作为部署入口，保留其子目录。识别不依赖页面名称，不跨来源、不跟随跳转，不携带账号、Cookie 或 Key。网页内容或普通结构化数据不能作为识别成功依据；无法连接、限流和服务异常明确提示。识别有时间限制，期间显示进度并沿用提交互斥；失败保留已有账号和设置，成功后才打开登录窗口。内部组件接收已确定的入口，不重复识别；页面回显实际地址，登录和账户读取复用该地址，模型请求使用单独保存的 API 地址。HTTP 显示未加密提示，厂商资料来源限制保持独立。外层仅保留主程序，凭据辅助组件放在内部目录。

网站地址和 API 地址分工明确。API 初始值采用识别后的网站地址，不读取站点其他配置代替用户决定。同网站刷新或重新登录保留手动值，换网站默认重置为新网站；输入网站发生变化时暂停旧账户操作。API 地址在测试、读取模型或预览切换时保存；刷新账户只访问网站，不受 API 草稿影响。地址支持根路径和已带版本路径的形式，统一转换后用于模型请求和配置预览，避免重复版本路径。

连接检查弹窗逐项显示网站、登录、Key 访问的通过、失败或未检测及原因。站点不能确认时不发送已有凭据；登录凭据仅发往其原网站，选中 Key 仅发往用户指定的 API。缺前置条件不做无意义请求，测试不写入 Codex、不发送模型对话。登录失效清除认证能力，Key 失效不误清除网站登录。

## 5. 核心规则设计

模型名精确匹配元数据；元数据内容保留来源，配置写入前交给安装中的 Codex 解析器验证。手工添加仅提供模型名称，不虚构上下文或思考档位。用户可显式导入完整模型目录补充参数来源。

官方刷新保存当前结果和每个来源最后一次成功的比较记录，两者用途分开。只有来源配置一致且存在成功记录时才比较模型名称；初次读取、变更来源配置时只建立记录。失败结果保持空模型及错误信息，成功记录仅供下次比较，不能充当本次展示数据。旧版成功缓存升级为初始比较记录；“本次新发现”随当前成功结果保存，下一次刷新重新计算。新标记不受模型是否已配置影响，列表稳定地将新发现项前置。

本地配置保留原有提供商、其他工具配置和原模型条目。用户明确新增的模型设为列表可见，能力参数保留来源值。应用新的连接时增加本工具的独立提供商条目；连接变化列入确认预览，第一版默认模型保持不变。目录使用版本化文件，先完成目录和凭据准备，再原子替换配置引用。若启用中的配置档案覆盖待修改内容，要求先处理覆盖关系，避免写入后无效。

## 6. 异常分流

网络、登录、站点格式和模型参数问题显示各自原因；HTTPS 中断、证书验证、域名解析、超时和拒绝连接分别提示，错误不带原始请求或凭据。不自动更换站点、密钥或模型，不自动代填未知能力。若当前 Codex 版本不能解析生成结果，则拒绝应用。若外部编辑使快照不一致，则重新准备方案。

## 7. 幂等与并发

页面提交期间禁用相关按钮；本地应用对写入操作加互斥锁；预览方案一次性消费；配置替换前再次检查文件摘要。按精确模型名去重。账户刷新开始即失效旧预览，并禁止重复刷新；网络读取在会话锁外进行，完成后核对会话代次和客户端身份才提交。退出或切换账号后，旧响应不能恢复账号或覆盖新资料。页面提交继续共用忙碌门闩。

## 8. 补数、重试与恢复

失败后由用户明确点击重试。密钥读取必须遍历分页，并核对读取数量。每次应用保存原配置的加密备份；恢复也是显式操作，先保存恢复前状态。仅恢复对应 Codex 目录的本工具备份，不能传入任意文件路径读取秘密。

## 9. 权限边界

应用以当前 Windows 用户运行，不需要管理员权限。桌面页面仅连接本机随机端口；本地操作需要随机会话令牌并核对来源。站点页不共享本地操作桥。API Key 使用当前 Windows 用户加密，供 Codex 的凭据命令读取；配置中不直接保存 Key。登录会话只保留在本次运行内。

## 10. 查询回看与运维定位

界面展示每个官方来源的刷新时间和错误信息、当前配置路径、当前模型、变更预览和备份列表。错误不得包含完整 Key、站点登录凭据或原始带认证的请求。实现说明记录构建版本、验证方式及未验证边界。
