# 模桥 ModelBridge

版本：v0.1.5；日期：2026/10/21。

面向 Windows 的本地模型配置工具，帮助用户登录自己的 Sub2API 站点、选择 API Key、发现模型并追加到 Codex。

- [需求文档](需求文档.md)：目标、用户流程、业务边界和验收。
- [设计文档](设计文档.md)：本地运行、职责、状态、写入和恢复设计。
- [整体实现说明](整体实现说明.md)：接口、文件布局、构建、运行和验证。
- [2026年10月迭代记录](2026年10月迭代记录.md)：实现进度、验证记录与审查结果。

本工具独立运行，不属于广告投放业务系统。没有 SQL 变更。
